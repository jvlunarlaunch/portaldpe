# Supabase Setup Guide for Portal DPE

Este guia contém todos os comandos SQL e passos manuais necessários para replicar o banco de dados do Portal DPE em um novo projeto Supabase.

## 1. SQL Schema

Execute o script abaixo no **SQL Editor** do seu painel Supabase para criar todas as tabelas e relacionamentos necessários.

```sql
-- 1. Create Authors Table (Extends Supabase Auth)
create table authors_portaldpe (
  id uuid references auth.users not null primary key,
  name text not null,
  username text unique not null,
  bio text,
  avatar_url text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Create Categories Table
create table categories_portaldpe (
  id bigint generated by default as identity primary key,
  name text unique not null,
  slug text unique not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Create Articles Table
create table articles_portaldpe (
  id bigint generated by default as identity primary key,
  title text not null,
  slug text unique not null,
  excerpt text,
  content text,
  image_url text,
  read_time text,
  featured boolean default false,
  main boolean default false,
  show_thumbnail boolean default true,
  show_author boolean default true,
  status text default 'draft', -- 'draft' or 'published'
  author_id uuid references authors_portaldpe(id) not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);

-- 4. Create Article_Categories Junction Table (Many-to-Many)
create table article_categories (
  article_id bigint references articles_portaldpe(id) on delete cascade not null,
  category_id bigint references categories_portaldpe(id) on delete cascade not null,
  primary key (article_id, category_id)
);

-- 5. Enable Row Level Security (RLS)
alter table authors_portaldpe enable row level security;
alter table categories_portaldpe enable row level security;
alter table articles_portaldpe enable row level security;
alter table article_categories enable row level security;

-- 6. Create RLS Policies

-- Authors: Public Read, Auth Update
create policy "Authors are viewable by everyone" 
  on authors_portaldpe for select using (true);

create policy "Users can update their own author profile" 
  on authors_portaldpe for update using (auth.uid() = id);

create policy "Users can insert their own author profile" 
  on authors_portaldpe for insert with check (auth.uid() = id);

-- Categories: Public Read, Auth Insert/Update (Simplified for now)
create policy "Categories are viewable by everyone" 
  on categories_portaldpe for select using (true);
  
create policy "Authenticated users can manage categories" 
  on categories_portaldpe for all using (auth.role() = 'authenticated');

-- Articles: Public Read (if published), Auth ALL
create policy "Articles are viewable by everyone" 
  on articles_portaldpe for select using (true);

create policy "Authenticated users can manage articles" 
  on articles_portaldpe for all using (auth.role() = 'authenticated');

-- Junction Table: Public Read, Auth ALL
create policy "Category links are viewable by everyone" 
  on article_categories for select using (true);

create policy "Authenticated users can manage category links" 
  on article_categories for all using (auth.role() = 'authenticated');
```

## 3. Configuração Manual (Storage)

Estes passos precisam ser feitos manualmente no menu **Storage** do Supabase, pois não podem ser feitos via SQL Editor padrão.

1.  Acesse o menu **Storage**.
2.  Crie um novo bucket chamado: `blog-media`.
3.  Defina o bucket como **Public**.
4.  Adicione as seguintes regras de política (Policies) para o bucket:

    *   **SELECT (Read):** Permita acesso a todos (`ANON`).
    *   **INSERT (Upload):** Permita apenas para usuários autenticados (`AUTHENTICATED`).
    *   **UPDATE/DELETE:** Permita apenas para usuários autenticados (`AUTHENTICATED`).

## 4. Trigger para Auth (Opcional mas recomendado)

Para garantir que todo usuário criado no Auth do Supabase tenha automaticamente uma entrada na tabela de autores.

```sql
create function public.handle_new_user() 
returns trigger as $$
begin
  insert into public.authors_portaldpe (id, name, username)
  values (new.id, new.raw_user_meta_data->>'name', new.email);
  return new;
end;
$$ language plpgsql security definer;

create trigger on_auth_user_created
  after insert on auth.users
  for each row execute procedure public.handle_new_user();
```
